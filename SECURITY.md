# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in react-native-usesense, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

### Contact

Email: [security@usesense.ai](mailto:security@usesense.ai)

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response Timeline

- **Acknowledgment**: Within 2 business days
- **Initial assessment**: Within 5 business days
- **Resolution target**: Within 30 days for critical issues

### Process

1. Report the vulnerability via email
2. We will acknowledge receipt and begin investigation
3. We will work with you to understand the scope and impact
4. A fix will be developed and tested
5. A new version will be released with the fix
6. We will publicly disclose the vulnerability after the fix is available (coordinated disclosure)

### Scope

This policy applies to the react-native-usesense npm package, including:

- TypeScript source code (`src/`)
- Native iOS bridge code (`ios/`)
- Native Android bridge code (`android/`)
- Build and distribution configuration

The native UseSense iOS and Android SDKs have their own security policies. Issues in the native SDKs should also be reported to [security@usesense.ai](mailto:security@usesense.ai).
